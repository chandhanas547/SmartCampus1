## Free-tier tradeoffs and sources

Render Free services sleep after 15 idle minutes and can take about one minute to wake. The filesystem is ephemeral; all persistent accounts, sessions, auth limits and lending state belong in Atlas. Free services have no shell or one-off jobs. Use a dedicated free workspace without a payment method: quota exhaustion must suspend service/builds, not bill overages. If that condition cannot be met in the available account, stop before creating resources. Free rollback history is limited, so record the exact successful Git commit. See [Render Free limits](https://render.com/docs/free).

Atlas Free currently uses MongoDB 8.0 and three replicated nodes, with one Free cluster per project. This is a suitable candidate for the required transaction-capable topology, but real transactions/indexes/roles must still pass on the actual approved cluster. Do not assume local acceptance proves cloud behavior. See [Atlas Free limits](https://www.mongodb.com/docs/atlas/reference/free-shared-limitations/).

The Blueprint uses documented manual deployment, secret prompts and generated session-secret fields. Build installs development dependencies explicitly even with NODE_ENV=production, builds once, then prunes development dependencies. This exact shape was verified locally. See [Render Blueprint fields](https://render.com/docs/blueprint-spec).
